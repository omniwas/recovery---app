📲 Chrome Home Screen & HTTP Setup

Step 1: Online HTTPS ya Local HTTP par Chalayein
Chrome me Add to Home screen tabhi kaam karta hai jab file https:// ya http:// link se khuli ho (sidha file:/// se nahi):
  • Sabse Aasan (Free Live Link): Diye gaye jen-r2-recovery-pwa.zip (ya is file ko index.html naam dekar) app.netlify.com/drop par drag-and-drop karein. Turant permanent link mil jayega.
  • Local Wi-Fi HTTP Server (PC/Termux): Jis folder me file hai wahan python -m http.server 8080 chalayein aur mobile Chrome me http://localhost:8080 ya PC ka IP kholein.
Step 2: Mobile Chrome se Home Screen par Layein
1. Mobile ke Google Chrome me apna link kholein.
2. Upar 📲 Add to Home Screen button dabayein, ya Chrome ke upar right corner me 3 dots (⋮) par tap karein.
3. Install app ya Add to Home screen select karke Add / Install dabayein.
4. Ab aapke mobile ki Home Screen par JEN R-II Recovery ka icon aa jayega aur bina browser address bar ke full-screen khulega!
